# Money Manage

A lightweight, single-page money dashboard (rupee-first) that shows balance,
cash flow, budget progress, goals, and recent transactions with a modern UI.

## Preview

Open `index.html` directly in your browser or start a quick local server:

```bash
npx serve .
```

Then visit the printed URL (typically http://localhost:3000).

## Developing

- The dashboard uses Indian Rupees (INR) and Indian number formatting by
  default. Update data in `script.js` to reflect your own income, expenses,
  budgets, and goals.
- Styles live in `styles.css` and use CSS variables for quick theme tweaks.
- No build step is required; everything runs in the browser.
